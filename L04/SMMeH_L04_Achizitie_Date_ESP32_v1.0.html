Simulator didactic. ADC-ul este modelat ideal (liniar, 12 biți) pe intervalele recomandate de Espressif pentru ESP32; ADC-ul real are neliniarități și se folosește cu calibrare (analogReadMilliVolts). Semnalul e-health este sintetic, iar zgomotul este pseudo-aleator, reproductibil pentru același N.

Varianta individuală

Ce investighezi

Semnalul variantei tale imită ieșirea analogică a unui senzor PPG: o componentă continuă, o undă pulsatilă lentă, o perturbație de rețea de 50 Hz și zgomot. Îl „citești” cu un ADC de tip ESP32 și decizi atenuarea, frecvența de eșantionare, filtrul și calibrarea.

Parcurs propus (≈ 100 de minute)

  1. Aplică N și notează datele impuse.
  2. Calculează pe hârtie mărimile din fila 3 (LSB, cod, alias, M, τ, calibrare).
  3. Parcurge experimentele A–E și compară cu calculul; notează câte un caz pentru fiecare.
  4. Verifică răspunsurile, scrie concluziile, tipărește fișa sau salvează PDF.

Ce predai

Fișa (PDF) cu N, calculele cu unități, cazurile notate și trei concluzii. Numele fișierului: SMMeH_L04_Nxx_Nume_Prenume.pdf. Opțional: proba fizică pe ESP32 din îndrumar.

Ipotezele modelului

  • ADC ideal de n biți: cod = round(U / U_max · (2ⁿ − 1)), limitat la 0 … 2ⁿ − 1.
  • U_max = limita superioară recomandată a atenuării (950 / 1250 / 1750 / 2450 mV); sub limita inferioară (100 sau 150 mV) citirea este marcată nesigură.
  • În experimentul D, canalul are o eroare de câștig și un offset proprii variantei.

Breviar

Cuantizare
LSB = U_max / (2ⁿ − 1) ≈ U_max / 2ⁿ; cod = round(U / LSB); e_q ∈ [−½ LSB, +½ LSB]

ESP32: ADC SAR de 12 biți (0 … 4095). Intervalele recomandate (ESP-IDF): 0 dB 100–950 mV, 2,5 dB 100–1250 mV, 6 dB 150–1750 mV, 11 dB 150–2450 mV. Se folosește ADC1 (GPIO32–39); ADC2 nu se folosește cu Wi-Fi activ.

Eșantionare și aliasing
fₛ > 2·f_max; f_alias = | f − k·fₛ |, k ales astfel încât rezultatul să fie în [0, fₛ/2]
Filtre
MA: y[n] = (1/M) Σ x[n−k]; întârziere (M−1)/2 eșantioane; M = fₛ/50 anulează 50 Hz
EMA: y[n] = α x[n] + (1−α) y[n−1]; τ ≈ Tₛ/α

Medianul elimină vârfurile izolate, nu și perturbația periodică.

Calibrare
U = a·mV_citit + b; a = (U₂ − U₁)/(c₂ − c₁); b = U₁ − a·c₁
