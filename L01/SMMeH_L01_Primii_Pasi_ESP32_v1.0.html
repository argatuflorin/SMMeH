1. Ce face un microcontroler

Placa și programul

Microcontrolerul execută instrucțiuni și interacționează cu intrări și ieșiri. Placa de dezvoltare adaugă alimentare, conector USB și pini accesibili. GPIO este un pin configurabil de intrare sau ieșire.

setup() rulează o dată după pornire sau resetare. loop() se repetă. pinMode() configurează pinul; digitalWrite() comandă o ieșire; digitalRead() citește o intrare.

De la montaj la e-health

Butonul produce o informație binară. DHT22 oferă temperatură și umiditate ambientală printr-o interfață digitală. Un mesaj serial permite observarea rezultatului.

În această lucrare măsurăm mediul unei încăperi. DHT22 nu este un termometru clinic pentru temperatura corpului. Home Assistant și VM vor fi folosite la integrare, după achiziția locală.

Intrare → program ESP32 → ieșire / mesaj serial

HIGH / LOW sunt stări logice. În schema LED-ului extern, HIGH aprinde LED-ul. Cu INPUT_PULLUP, butonul dintre GPIO și GND produce LOW când este apăsat.

2. Pregătirea laboratorului

Necesar: placă ESP32 cu model identificabil, cablu USB de date, laptop, breadboard, LED roșu, rezistor de 330 Ω, buton, modul DHT22 cu marcaje, fire și multimetru. Un set poate fi folosit în echipă; fiecare student execută N propriu.

  1. Identifică ESP32 clasic WROOM sau ESP32-S3. Citește pinout-ul plăcii exacte; numerele GPIO nu sunt pozițiile fizice în conector.
  2. Instalează Arduino IDE. În Preferences / Additional Boards Manager URLs adaugă https://espressif.github.io/arduino-esp32/package_esp32_index.json.
  3. În Boards Manager instalează esp32 by Espressif Systems. Alege modelul exact și portul USB. Notează versiunile IDE și pachetului.
  4. Deschide programul 01_Serial descărcat mai jos. Apasă Verify, apoi Upload. Deschide Serial Monitor la 115200 baud. Resetează placa și urmărește mesajul cu N.
  5. Pentru DHT22, în Library Manager instalează DHT sensor library by Adafruit și Adafruit Unified Sensor.
Dacă nu apare portul sau nu se încarcă programul

Încearcă un cablu de date cunoscut, reconectează placa și identifică portul nou. Verifică driverul adaptorului USB al plăcii. Închide alte aplicații care ocupă portul. Pentru procedura BOOT/RESET și opțiunile USB ale S3 urmează documentația plăcii; nu schimba la întâmplare setările memoriei. Cu USB nativ S3, opțiunea USB CDC On Boot poate fi necesară pentru mesaje Serial pe acel port.

3. Datele individuale

Generator SMMeH-L01-1.0. N este indicele atribuit în Moodle, nu ID-ul contului. Domeniul acestei ediții este 1–42; N=7 este rezervat exemplului și nu se atribuie unui student. Nu alege N al altui coleg.

tON = 400 + 100N ms; tOFF = 600 + 100(N mod 5) ms
Ts = 2500 + 500(N mod 3) ms

„mod” înseamnă restul împărțirii întregi. Exemplul DEMO folosește N = 0 exclusiv pentru demonstrație. Fișa evaluată folosește N atribuit. Grupa identifică exportul; timpii depind numai de N și versiune. Schimbarea profilului modifică pinii, nu timpii.

După editare apasă „Aplică varianta N”. Simulatorul și descărcările folosesc configurația aplicată, afișată mai sus. Aplicarea resetează rularea și răspunsurile fișei.

4. Schema explicată

Schemă funcțională, nu desen al conectorului. LED: GPIO → rezistor → anod; catod → GND. Rezistorul poate fi oriunde în aceeași ramură serie. Butonul se află între GPIO și GND; la butoanele cu patru pini verifică perechile deja unite.

DHT22: citește marcajele VCC / DATA / GND ale modulului exact. Nu presupune aceeași ordine la toate modulele. Folosește 3,3 V și pull-up DATA–3V3 conform modulului; dacă lipsește, adaugă 4,7–10 kΩ conform documentației. Nu aplica 5 V pe GPIO.

Calcul înaintea montajului

T = tON + tOFF; f = 1000 / T[ms]
D = 100 · tON / T [%]
I ≈ (3,3 − VF) / 330 [A]

Pentru exemplul didactic VF = 2,0 V: I ≈ 3,94 mA. VF și tensiunea reală de ieșire depind de LED și de sarcină; verifică prin măsurare. D este factorul de umplere al clipirii lente, nu o comandă PWM hardware.

Înainte de alimentare

Bifarea este o fișă de lucru; verificarea fizică rămâne necesară. Măsoară tensiunea în paralel, iar curentul numai în serie, cu aparatul configurat corect.

Ce trebuie să observi
A: LED-ul pornește aprins la t = 0. Notează trei începuturi succesive ale aprinderii și două perioade. B: apasă și eliberează; notează nivelul brut și LED-ul. Simulatorul folosește un buton ideal, fără rebond. C: prima citire se face la Ts. Obține cinci citiri, apoi provoacă o eroare. Eroarea se consumă la următoarea citire; ultima valoare validă este păstrată cu vechime, iar starea devine eroare. Modifică temperatura și observă că afișajul se actualizează abia la citire.


6. De la simulator la placa reală
Descărcările sunt generate pentru configurația aplicată. Fiecare fișier .ino se păstrează într-un folder cu același nume. Încarcă pe rând sketch-urile; fiecare îl înlocuiește pe cel anterior.
Cum citești programul
const declară o valoare nemodificată în timpul rulării. unsigned long păstrează timpi în milisecunde. delay() blochează fluxul secvențial din loop; nu oprește toate serviciile interne ale ESP32. În programul de buton, LOW înseamnă apăsat. În programul DHT22, isnan() identifică o valoare invalidă, nu temperatura zero.
Extensie pentru cei cu experiență
În 05_Bonus, clipirea folosește millis(). Butonul aprinde un al doilea LED de diagnostic pe GPIO16 (clasic) sau GPIO15 (S3), fiecare cu rezistor de 330 Ω. Butonul poate fi citit în timp ce primul LED clipește. Timpul citirii senzorului nu este inclus în această extensie.
Probe fizice: serial cu N propriu; clipire și perioadă măsurată pentru trei cicluri; buton apăsat/eliberat; minimum cinci citiri valide DHT22. Oprește alimentarea înainte de a deconecta DATA pentru proba de eroare, apoi realimentează. Dacă senzorul lipsește, declară proba neexecutată și păstrează simularea separat.
